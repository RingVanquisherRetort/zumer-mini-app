# ZUMER Mini App

Static frontend prototype for the ZUMER courier ecosystem, designed to run as a Telegram Mini App.

## Included
- Responsive dark graphite / lime interface.
- Home, onboarding, personal cabinet and support screens.
- City selection and two onboarding paths (self-service / manager assistance).
- Language selector placeholder for RU, TJ, UZ, TK, KK and KY.

## Current limitations
This is a **frontend prototype only**. The form does not send or store submissions. Do not enter real personal data yet. Before collecting leads, connect a secure backend, validate Telegram WebApp initData server-side, add a published privacy notice and consent flow, and configure the official partner registration URL. Activation status must come from a verified partner source or manager confirmation, not from a link click.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then Save.
4. Wait for the Pages deployment. The initial URL will be `https://ringvanquisherretort.github.io/zumer-mini-app/`.

Do not set the Telegram menu button to a URL until the published page has been tested inside Telegram.
